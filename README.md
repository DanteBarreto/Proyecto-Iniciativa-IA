# Apetito de riesgo de las iniciativas de IA

Indicadores de apetito de riesgo de las iniciativas de IA de Credicorp, para la presentación a la alta dirección del 2 de diciembre de 2026. **Contenido confidencial, uso interno.**

## Estructura

| Carpeta | Contenido |
|---|---|
| `Grabaciones/` | Grabación y transcripción de la reunión de requerimientos. |
| `Inputs/` | Insumos fuente, sin modificar: playbook de iniciativas IA, 3 Excel de riesgo no financiero (RNF) y el correo del checkpoint de Gobierno IA. |
| `01_Analisis_Requerimientos/` | Análisis de la reunión: requerimientos, actividades y plan. |
| `02_Analisis_Playbook/` | Comparación entre hojas, estadísticas descriptivas y propuesta de indicadores del playbook. |
| `03_Analisis_Insumos_RNF/` | Revisión de los 4 insumos RNF y piloto de indicadores con 12 iniciativas (Excel calculadora). |
| `04_Calculo_Indicadores/` | Primer ejercicio de los 6 KRI propuestos por Walter: valores, umbrales propuestos, semáforo y datos faltantes (Excel calculadora). |
| `06_Reporte_HTML/` | Prototipos del reporte HTML (híbrido de diapositivas + anexo, y dashboard de una página) con **datos de ejemplo**. |

Cada entregable tiene un `.md` con la conclusión y un `.xlsx` con el detalle.
Los archivos de `Inputs/` y `Grabaciones/` no se editan; los análisis se guardan en carpetas numeradas.
